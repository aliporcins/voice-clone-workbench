🎙️ 声音克隆工作台

录一段你的声音 → 保存到声音库 → 输入文字 → 用 Qwen3-TTS 生成你的声音

🔒 隐私：声音默认只存在你的浏览器里（IndexedDB），不上传服务器；只有你点「生成」时，才会把声音发给 Hugging Face 或你自己传进 Colab。

1录音

建议录 10–30 秒，安静环境，自然说话（读一段你平时说的话就行）。录完会自动转成 16kHz 单声道 WAV，Qwen3-TTS 最喜欢这个格式。

00:00
点「开始录音」，浏览器会请求麦克风权限（手机上也可以录）。

2声音库

声音存在你的浏览器里，换浏览器或清数据会丢失。点「设为当前」选一个声音用来生成。

还没有保存的声音，先去上面录一段吧。

3输入文字

长文本会自动按约 120 字切段（一次生成别太长，分段更稳），每段单独生成。

0 字 · 0 段

4生成语音

A · 直接生成（Hugging Face 免费）

用阿里 Qwen 官方的 Hugging Face Space（Qwen/Qwen3-TTS）在线生成。免费，但要排队，匿名额度有限；声音会发到 Hugging Face 的服务器。

B · Colab 生成（免费 T4，最稳）

免费 Colab T4 跑 Qwen3-TTS 1.7B，不排队、不限量（受 Colab 免费额度限制）。把语音包下载下来，传进 Colab 跑。

  1. 先在上面选好声音、输好文字，点「下载语音包」。
  2. 点「在 Colab 打开笔记本」，运行时选 T4 GPU。
  3. 按笔记本里的顺序运行：装依赖 → 上传语音包 → 加载模型 → 生成 → 下载音频。
  4. 首次加载模型约 1–2 分钟（3.86GB），之后每段几十秒出音频。
两条路的区别：A 路点一下就出，不用装东西，但可能排队、额度用完；B 路稳得多，就是要多走几步（下载包、传 Colab、运行）。着急先试 A，A 不行就走 B。
模型：Qwen3-TTS 1.7B-Base（阿里 Qwen 团队，开源 Apache-2.0）· 在线生成：Hugging Face Space Qwen/Qwen3-TTS · 本工具不收集任何声音和文字。
